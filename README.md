# 🇵🇰 Pakistan Zindabad — 79th Independence Anniversary Tribute Website

A flagship, ultra-premium, interactive website built to celebrate Pakistan’s **79th Independence Anniversary (1947 – 2026)**. Packed with cinematic splash animations, patriotic background music, 3D interactive carousels, military tributes, and historical landmark explorer modals.

## 🌟 Live Demo

Check out the live website:

---

## ✨ Flagship Features & Experience

### 🎆 1. Cinematic Video Splash Intro
- **Fireworks Burst Engine**: HTML5 Canvas fireworks burst animation on splash load.
- **5-Second Progress Bar**: Smooth loading countdown with an instant "Skip Intro" option.

### 🎵 2. Background Patriotic Anthem Engine
- **Auto-Looping Anthem**: Plays *Ay Watan Pyaray Watan* in a seamless high-quality audio loop.
- **Smart Unmuted Sound Activation**: Unlocks unmuted audio on the first user interaction (touch, click, scroll) adhering to strict modern browser autoplay policies.
- **Header Audio Toggle**: Real-time Anthem ON/OFF toggle in the glassmorphism navigation header.

### 🏛️ 3. 3D Coverflow Landmarks Explorer
- **Interactive Carousel**: Infinite 3D coverflow slider featuring Pakistan's iconic landmarks (*Minar-e-Pakistan, Mazar-e-Quaid, Faisal Mosque, K2 Peak, Badshahi Mosque, Gwadar Port, Hunza Valley, Bab-e-Khyber, Rohtas Fort*).
- **Historical Detail Modal**: Clicking any landmark card opens a blurred glass backdrop modal displaying rich historical facts and details.

### 🎖️ 4. Architects of Freedom & National Heroes
- Dedicated tribute pillars honoring **Quaid-e-Azam Muhammad Ali Jinnah**, **Mohtarma Fatima Jinnah**, **Allama Muhammad Iqbal**, **Liaquat Ali Khan**, and **Major Raja Aziz Bhatti Shaheed (Nishan-e-Haider)**.

### 🛡️ 5. Armed Forces Tribute Ribbon
- Dynamic marquee ribbons highlighting the **Pakistan Army**, **Pakistan Air Force**, **Pakistan Navy**, and **SSG Commandos** (*Man Janbazam*).

### 🕌 6. Spiritual Heritage & National Poetry
- Interactive cards featuring Allama Iqbal’s *Lab Pe Aati Hai Dua* and Hafeez Jalandhari’s *Qaumi Taranah*.

### 📸 7. Masonry Photo Gallery — "Yaadgar Lamhe"
- Grid photo gallery capturing memorable moments, national celebrations, and scenic landscapes of Pakistan.

### 📱 8. 100% Responsive & Mobile Optimized
- Pixel-perfect responsive layout for smartphones, tablets, laptops, and desktop screens with custom touch navigation.

- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Styling**: Modern Glassmorphism, CSS Grid, Flexbox, Keyframe Animations
- **Typography**: Google Fonts (*Poppins*, *Playwrite AU QLD*)

## 🚀 Local Development Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/usamafaheem-dev/Pakistan_ZIndabad-Website.git
   ```

2. **Navigate to the Project Folder:**
   ```bash
   cd Pakistan_ZIndabad-Website
   ```

3. **Run Locally:**
   Open `index.html` directly in any web browser or use VS Code Live Server extension (`127.0.0.1:5500`).
